A single newspaper front page image titled "The World Today" that sums up world news from Thursday, 26 November 2026, in one image.

## The image

The image is a front page of "The World Today", 1024x1024 pixels. The lead story is the Houthi strikes on Saudi oil, presented as the main headline of the day. The rest of the front page carries the other world news of 26 November 2026 in short headlines and captions, so the whole day reads at a glance.

## Running it

Run `python3 main.py` from the repository root. The program copies `entry.png` from the same directory as `main.py` into the output directory given by the `MAKEFUN_OUTPUT_DIR` environment variable (default `/output`), as `entry.png`.
